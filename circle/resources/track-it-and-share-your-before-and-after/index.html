Monthly AI Check Tracker

Print this and keep it with your marketing notes, or copy it into a spreadsheet. Fill in one row each month, because AI answers change over weeks, not days, so monthly is the right rhythm.

Set up (do once)

  • ☐ Monthly reminder called "AI check" added to the diary
  • ☐ Reminder set for the same day each month (e.g. first Monday)
  • ☐ The 3 ChatGPT questions from lesson 1 written out word for word below
  • Question 1: ____________________________
  • Question 2: ____________________________
  • Question 3: ____________________________

Each month: run the check

  • ☐ Re-run your score (Premium members: use the AI Visibility skill, which keeps the tracker for you)
  • ☐ Ask ChatGPT question 1 and note if your practice is named
  • ☐ Ask ChatGPT question 2 and note if your practice is named
  • ☐ Ask ChatGPT question 3 and note if your practice is named

Each month: record the results

  • Month: ____________
  • Score: ______ (last month: ______)
  • Mentioned in ______ of 3 ChatGPT answers
  • Fixes done since last check: ____________________________
  • Anything else that changed (new reviews, website updates, Google profile edits): ____________________________

Share and next steps

  • ☐ Score has climbed or ChatGPT has started naming us, so post the before and after in the Wins category
  • ☐ Next fix to work on before the next check: ____________________________
  • ☐ Would rather have it done for you (fixes, free SEO health check, before-and-after report)? Message the team in the Circle
