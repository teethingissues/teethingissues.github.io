Questions

What is a mock CQC inspection?

A mock CQC inspection is a practice run of a Care Quality Commission (CQC) inspection, done before the real one. The Teething Issues CQC Calm Check looks at a dental practice the way an inspector would, against CQC’s five key questions: is the practice safe, effective, caring, responsive and well-led? A former CQC Registered Manager reads the practice’s real documents line by line, including staff files, the medical emergency kit and drug checks, decontamination and autoclave logs, COSHH assessments and fire and legionella risk assessments. For example, the staff file check flags a DBS certificate that isn’t Enhanced or is more than 3 years old. The practice receives a written action plan with every gap, who owns it and the date it should be fixed by.

What happens after a CQC Calm Check?

After a CQC Calm Check, the practice owner receives a written action plan and a 30-minute call to go through it with the team. Every gap found has an owner and a date, so the practice manager can work through the list in order of risk. Many practices close the gaps themselves using the plan. Practices that want the work done for them can move on to the Teething Issues Compliance OS, which keeps a practice calm and in order for CQC all year with 481 checks across 20 departments. There is no obligation to go further: the action plan belongs to the practice either way.
